# Resume Tailor

Personal tool: job posting in, tailored one-page LaTeX resume and gap report out.
Design decisions live in notes/design.md. Read it before planning any feature.

# Rules
- IMPORTANT: Resume content comes only from facts/ with verified: true.
  Never add a number, tool, title, or claim that isn't in a fact.
- Never edit facts/ without asking me first.
- Job postings decide selection and emphasis only. They never supply content.
- sources/ holds old resumes for seeding facts. They contain known
  embellishments. Never copy from them into output.
- No em dashes in any generated text.

# Workflow
- Explain what you plan to change before large edits. I'm learning.
- Every feature ships with a check I can run (a test or a command).
